## Análise de Performance e Estratégia de Portfólio - AluraStoreBR

Este repositório contém uma análise técnica e estratégica das operações da **Alura Store BR**, abrangendo quatro unidades de negócio. O projeto utiliza Ciência de Dados para avaliar KPIs (Key Performance Indicators) e fundamentar decisões sobre a otimização da rede de lojas. O objetivo principal é avaliar a performance financeira, operacional e de satisfação de cada loja para subsidiar decisões de otimização de portfólio, que no caso é indicar a venda de uma das 4 lojas da rede.<br><br>

## 📋 Resumo do Projeto
Neste projeto, o propósito é aplicar na prática os seguintes conceitos da trilha Fundamentos de Python e Dados G9 - ONE:
-    Realizar o carregamento e manipulação dos dados de arquivos CSV utilizando a biblioteca Pandas;
-    Aplicar os conceitos aprendidos durante a trilha para criar visualizações gráficas dos dados através da biblioteca Matplotlib;
-    Fazer a análise de certas métricas como faturamento, avaliações e desempenho de vendas.

A análise foi desenvolvida em Python para processar grandes volumes de dados transacionais, visando identificar padrões de consumo, eficiência logística e saúde financeira de cada unidade. O desfecho do estudo fornece uma recomendação baseada em dados sobre a continuidade operacional das lojas.

## 🚀 Etapas da Análise Técnica

O fluxo de trabalho foi dividido em quatro fases principais, utilizando Python e a biblioteca Pandas:

### 1. Ingestão e Tratamento de Dados
* **Extração:** Coleta de dados de quatro fontes distintas (arquivos CSV) representando as unidades da rede.
* **Limpeza:** Verificação de tipos de dados, tratamento de datas e identificação de valores nulos ou inconsistentes para garantir a integridade das métricas.

### 2. Análise Exploratória (EDA)
Nesta etapa, foram analisadas as variáveis fundamentais de cada transação:
* **Mix de Produtos:** Identificação das categorias mais vendidas e sua representatividade no faturamento.
* **Métricas Financeiras:** Cálculo de preços por loja e volume de vendas por categoria.
* **Logística:** Avaliação do custo médio de frete por loja e categoria de produto.
* **Comportamento do Consumidor:** Análise da Média das avaliações feitas pelos clientes.

### 3. Visualização de Dados
Utilização de bibliotecas gráficas para identificar padrões:
* **Performance por Loja:** Comparativo de faturamento de vendas e de vendas por categoria entre as unidades das lojas.
* **Qualidade de Serviço:** Análise das notas de avaliação da compra (1 a 5).

### 4. Diagnóstico Estratégico
A análise culminou na comparação direta entre as unidades, focando em:
* **Rentabilidade:** Identificação de categorias mais lucrativas (eletrônicos, móveis, etc.).
* **Eficiência Operacional:** Comparação de fretes e competitividade de mercado.<br><br>

## 📊 Principais Conclusões

Após a análise comparativa, a **Loja 4** apresentou os indicadores mais críticos, levando à recomendação estratégica de venda desta unidade. Os pontos determinantes foram:
* **Falta de Diferencial:** Ausência de vantagem competitiva relevante em relação às outras lojas.
* **Mix de Produtos Ineficiente:** Menor participação nas categorias de maior margem e demanda.
* **Desempenho Financeiro:** Retorno estratégico e financeiro inferior, impactando a margem global da empresa.

---
**Conclusão:** A decisão de desinvestimento na Loja 4 permite a realocação de recursos para as unidades com melhor performance, potencializando o crescimento e a eficiência operacional da Alura Store BR.<br><br>
